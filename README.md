# SecretsCompass

SecretsCompass leads you through WoW: Forever secrets one step at a time. Choose from fifteen Alliance or fourteen Horde built-in routes, including the Manual Scavenger Hunt and the known Dawn Waker steps, or select a guide in SecretChecklist.
